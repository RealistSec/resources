## 🔥 Featured: Antigravity Skills & Workflows

> **The crown jewels of this repo.**

Custom skills and workflows for [Google Antigravity](https://antigravity.google) the agentic AI development platform. Delegate complex tasks to autonomous AI agents using tools like [Opencode](https://opencode.ai) and [Oh My OpenCode](https://github.com/code-yeongyu/oh-my-opencode). 

<details>
<summary><b>🚀 OpenCode Orchestrator</b> — Delegate tasks to terminal AI agents</summary>

### What it does
Hands off multi-file refactoring, long-running code generation, and deep codebase exploration to [OpenCode](https://opencode.ai)—a terminal-based autonomous AI.

### Quick Start
```
/use-opencode
```

| Best For | Not For |
|----------|---------|
| Multi-file refactoring (15+ files) | Quick single-file edits |
| Long-running code generation | Browser testing |
| Deep codebase exploration | Interactive debugging |

**[→ Full Documentation](skills/opencode-orchestrator/SKILL.md)**

</details>

<details>
<summary><b>🧠 Oh My OpenCode Orchestrator</b> — Multi-agent AI workflows</summary>

### What it does
Enhanced orchestration for [Oh My OpenCode](https://github.com/code-yeongyu/oh-my-opencode) with pre-configured specialist agents.

### Quick Start
```
/use-omo-opencode
```
Magic keyword: `ultrawork` or `ulw`

| Agent | Specialty |
|-------|-----------|
| **Sisyphus** | Main orchestrator (Opus 4.5) |
| **Oracle** | Architecture & debugging (GPT 5.2) |
| **Frontend** | UI/UX development (Gemini 3 Pro) |
| **Librarian** | Documentation research (Sonnet 4.5) |
| **Explore** | Fast codebase grep (Grok Code) |

**[→ Full Documentation](skills/omo-opencode-orchestrator/SKILL.md)**

</details>

<details>
<summary><b>📦 Installation</b> — Get started in seconds</summary>

### Global Installation (All Projects)
```bash
# Copy skills
cp -r skills/* ~/.gemini/antigravity/global_skills/

# Copy workflows
cp skills/opencode-orchestrator/use-opencode.md ~/.gemini/antigravity/global_workflows/
cp skills/omo-opencode-orchestrator/use-omo-opencode.md ~/.gemini/antigravity/global_workflows/
```

### Single Project
```bash
cp -r skills/* /path/to/project/.agent/skills/
```

</details>
