# User Guide – GraphQL Schema Design Documenter

## Goal
Create a quick design summary from GraphQL SDL.

## Steps
1. Open `index.html`.
2. Paste your schema SDL.
3. Click **Document**.
4. Review counts (types, enums, inputs) and entrypoints with brief guidance.

## Tips
- Use this as a pre-review checklist before merging schema changes.
- Large schemas may need modular separation.
