# User Guide – Data Transfer Time Estimator

## Goal
Estimate transfer duration for a given payload size and connection speed.

## Steps
1. Open `index.html`.
2. Enter **Payload size (MB)**.
3. Pick a **Connection** profile.
4. Adjust **Protocol overhead** if needed.
5. Click **Estimate** and read the ETA and throughput details.

## Tips
- Increase overhead for TLS-heavy uploads or VPN links.
- For gigabit LAN tests, set overhead low (1–2%).
