# Data Transfer Time Estimator

Quickly estimate how long uploads or downloads take for different link speeds and protocol overhead.

- **Demo**: `index.html`
- **Docs**: `docs/user-guide.md`, `docs/dev-guide.md`
- **Screenshot**: `docs/screenshot.png`

## Quick start
Open `index.html`, set payload size, choose a connection, adjust overhead, and click **Estimate**.
